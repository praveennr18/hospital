# Healthcare Backend (Django)

This backend provides RESTful APIs for a healthcare application, supporting admin, doctor, and patient roles, appointment management, and CRUD operations. It uses Django REST Framework and JWT authentication, and follows HIPAA compliance best practices.

## Features
- User authentication (JWT)
- Role-based access: Admin, Doctor, Patient
- CRUD for doctors and patients
- Appointment management
- Security and privacy configurations for HIPAA

## Setup
1. Install Python 3.10+
2. Create and activate a virtual environment
3. Install dependencies
4. Run migrations
5. Start the development server
